# أداة توليد المحتوى التسويقي الذكي (Next.js)

أداة تسويقية متكاملة لتوليد المنشورات والإعلانات بلهجات مختلفة وبأعلى معايير جودة الواجهات.

## 🚀 كيفية الرفع على Vercel (في أقل من دقيقتين)

1. ارفع مجلد `marketing-app` إلى حسابك في **GitHub**.
2. اذهب إلى موقع [Vercel](https://vercel.com) وانقر على **Add New Project**.
3. اختر المستودع الخاص بك (Repository).
4. في قسم **Environment Variables** أضف المفتاح التالي:
   - `ANTHROPIC_API_KEY`: مفتاح Claude API الخاص بك من موقع Anthropic.
5. اضغط **Deploy** وسيكون موقعك جاهزاً وشغالاً 100%!

## 💻 التشغيل محلياً (Local Development)

```bash
cd marketing-app
npm install
npm run dev
```
افتح المتصفح على: `http://localhost:3000`
